# Changelog

Здесь перечислены заметные для пользователя изменения RubyMUD. Внутренние
рефакторинги и изменения тестовой инфраструктуры в журнал не включаются.

## [Unreleased]

### Добавлено

- **Запуск как systemd-сервис.** `make service-install` ставит и включает
  пользовательский юнит `rubymud`, `make deploy` собирает новую версию, атомарно
  устанавливает её в отдельный путь и перезапускает сервис, `make service-logs`
  показывает журнал. Сборки, тесты и E2E больше не влияют на работающий сервер.

## [0.2.0] - 2026-08-09

### Добавлено

- **Интерактивная карта.** Новый canvas-пейн `~map` поддерживает масштабирование,
  перемещение, этажи, поиск комнат по всем зонам, слежение за персонажем и
  восстановление обзора после перезагрузки страницы.
- **Редактор карты.** Можно создавать и редактировать комнаты, зоны, направленные
  выходы, межзонные переходы и порталы; для выходов настраиваются команда, вес,
  дверь, проходимость и запрет автоматического маршрута. Доступны групповой перенос
  комнат между зонами и undo.
- **Маршруты и автоходьба.** Взвешенный поиск пути позволяет предпочитать быстрые
  дороги коротким, но дорогим переходам. Сервер подтверждает каждый шаг, показывает
  прогресс, автоматически приостанавливает маршрут при препятствии или
  рассинхронизации и позволяет остановить его либо продолжить после исправления
  ситуации и повторной синхронизации.
- **Импорт карт.** Settings принимает ZIP-архивы с `.mm2` (Delphi DFM/TPF0),
  включая CP1251-имена файлов. Там же можно выбирать и удалять наборы карт.
- **Распознавание комнат.** Форматы блоков комнаты настраиваются в Settings,
  проверяются при сохранении и могут быть проиграны на последних строках выбранной
  сессии. Комнату можно записать вручную после просмотра изменений.
- **MCP для карты и игры.** Расширены инструменты чтения карты, маршрутизации,
  автоходьбы, редактирования топологии и пользовательских заметок о комнатах.
  MCP включается в Settings; там же создаётся или обновляется отдельный токен,
  если управление не закреплено за CLI или переменными окружения.
- **Безопасный первый запуск Web Access.** Без явного `--listen` сервер теперь
  слушает только `127.0.0.1:8080`. В App Settings можно отдельно задать пароль
  и сохранить `Local only` либо защищённый `Network access` для следующего
  запуска; интерфейс показывает текущий и сохранённый адреса и необходимость
  перезапуска. Небезопасный внешний bind без защиты завершается ошибкой.
- **Навигация по live-буферу.** Добавлены локальный scrollback-регион, поиск по
  активному буферу и клавиши `PageUp`, `PageDown`, `End` и `Esc`.
- **История команд.** Стрелки выполняют поиск по префиксу, а `Ctrl+R` запускает
  безопасный обратный поиск по подстроке: первый `Enter` принимает найденную
  команду, второй отправляет её.
- **Цветной HTML-экспорт логов.** Автономный файл сохраняет ANSI-тему, выбранный
  диапазон и, по желанию, отправленные команды. Встроенный replay viewer умеет
  менять скорость и сжимает длинные паузы.
- **Часовой пояс сессии.** Можно следовать за часовым поясом браузера или закрепить
  IANA-зону вручную. Она используется для `$TIME`/`$DATE`, поиска и экспорта логов.
- **Редактирование Settings без потери позиции.** Алиасы, триггеры, подстановки,
  подсветки, hotkeys, переменные, профили и сессии редактируются прямо в строке;
  работают `Esc`, `Ctrl+Enter` и `Cmd+Enter`.
- **Локальные интеграции.** Добавлены отключённые по умолчанию команды `#exec` и
  `#webfetch`, которые разрешаются отдельно в Settings.
- `mudhost --version` показывает версию сборки; ту же версию сообщает MCP.
- HTTPS-ссылки в игровом выводе стали кликабельными, а входящий `BEL` вызывает
  визуальную вспышку активной панели.
- HTTP Basic Auth для веб-интерфейса включается и настраивается в Settings без
  перезапуска; в SQLite хранится только bcrypt-хеш пароля. Переменные
  `MUDHOST_BASIC_AUTH_USER` и `MUDHOST_BASIC_AUTH_PASS` остаются необязательным
  операторским override.

### Изменено

- Интерфейс маппера приведён к английскому языку; русские формулировки сохранены
  в плане будущего двуязычного каталога.
- Команды переходов карты проходят через обычный script pipeline, поэтому в них
  работают `;`, алиасы и переменные вроде `$mount`.
- Фильтры раздела Logs сохраняются в URL, а локальные диапазоны дат корректно
  переводятся в UTC с учётом зоны браузера или сессии.
- HTML-экспорт содержит канонический вывод MUD и выбранные отправленные команды;
  локальные echo и команды автологина в него не попадают.
- MCP по умолчанию отключён. Для сетевого доступа используется отдельная
  Bearer-аутентификация, а tokenless-режим разрешён только на loopback. Состояние и
  токен можно менять из Settings без перезапуска сервера, если они не заданы
  операторскими CLI/env override.
- Docker-образ больше не открывает wildcard-listener по умолчанию. Для
  опубликованного порта задайте `UI_LISTEN=0.0.0.0:8080` вместе с парой
  `MUDHOST_BASIC_AUTH_USER` / `MUDHOST_BASIC_AUTH_PASS` либо подготовленной
  базой. Для сетевого Web Access используйте TLS reverse proxy: Basic Auth по
  plain HTTP передаёт пароль в сети.

### Исправлено

- Восстановление последних строк при открытии сессии больше не сканирует всю
  многогигабайтную историю ради списка буферов.
- Live-вывод корректно догружается после восстановления сессии или пробуждения
  браузера; параллельно пришедшие строки сохраняют порядок и не дублируются.
- История команд больше не теряет позицию после восстановления и синхронизации
  вкладок.
- Открытие scrollback и поиска больше не мерцает и не пересоздаёт live-панель.
- Устранены скачки межстрочного интервала и высоты строк с command hints.
- Пересекающиеся правила подсветки корректно учитывают заданный порядок и
  восстанавливают предыдущие цвета и атрибуты после окончания совпадения.
- Фоновое обновление списка сессий больше не сбрасывает редактируемую строку.
- Часовые пояса работают в минимальных Alpine/Docker-образах без системной базы
  `tzdata`.

### Обновление

Перед первым запуском `v0.2.0` остановите `mudhost` и сделайте резервную копию
`data/mudhost.db`. При старте автоматически применяются миграции SQLite, включая
новую схему карты и настройки часовых поясов.
